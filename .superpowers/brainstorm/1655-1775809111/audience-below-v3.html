Advantage+ 受众 素材组 3
Advantage+ 受众无需手动配置。Meta 将自动寻找最合适的目标人群，在保持成本效益的前提下最大化覆盖范围。
交互逻辑：
· 点击 adset 节点（受众按钮或名称区域） → 下方受众配置区切换到该 adset；被选中的节点显示高亮环
· 点击受众类型按钮 → 循环切换 Adv+ / LAL / INT，同时配置区联动更新为对应类型的 UI
· Adv+：下方只展示说明文案，无需额外配置
· LAL：下方展示种子受众多选列表（复用现有 LAL 组件样式）
· INT：下方展示兴趣词 tags + 下拉搜索（完全复用现有 INT 组件）
