交互说明：
· 点击受众按钮 → 循环切换 Adv+ → LAL → INT → Adv+（保留现有 toggle 行为）
· 切换到 LAL 或 INT 时，架构图下方即时出现该 adset 的配置卡；切回 Adv+ 则配置卡消失
· 多个 adset 同时为 LAL / INT 时，各自的配置卡并排显示在架构图下方
· 每个配置卡右上角的「素材组 N」标签指明归属；连接线从对应 adset 节点延伸至配置卡
